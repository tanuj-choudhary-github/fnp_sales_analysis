# 📊 FNP Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes the sales data of Ferns and Petals (FNP) to uncover key insights related to revenue, customer behavior, and product performance. The goal is to help the business make data-driven decisions and improve overall sales strategy.

---

## 🎯 Objective

* To analyze overall revenue and sales trends  
* To identify top-performing products  
* To evaluate customer purchasing behavior  
* To analyze delivery time and operational efficiency  
* To compare sales across different occasions  
* To identify top cities contributing to orders  
* To improve business decision-making using data insights  

---

## 🛠️ Tools & Technologies
- Microsoft Excel  
- Data Cleaning  
- Data Transformation  
- Pivot Tables  
- Data Visualization (Charts & Dashboard)
